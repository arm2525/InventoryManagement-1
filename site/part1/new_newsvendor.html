Theory Essentials: The Stochastic Single-Period Problem

Duration: 30 Minutes References: Arrow, Harris, & Marschak (1951)

This is perhaps the most fundamental "stochastic" inventory problem. Unlike the EOQ or DLS models, we are not in a multi-period world. We have one chance to order, and this single order must satisfy all demand for the period.

The problem is defined by the "too much, too little" tradeoff.

  • If we order too much, we are left with unsold, perishable (or obsolete) inventory.
  • If we order too little, we miss out on potential profit from customers.

This model applies to seasonal goods (e.g., ski jackets), perishable items (e.g., newspapers, milk), or capacity decisions (e.g., booking airline seats).

1.1 Formal Definition & Marginal Analysis

We define the following parameters:

  • $D$ = Demand, a random variable with CDF $F(d) = P(D \le d)$ and PDF $f(d)$.
  • $c$ = Cost per unit (purchase cost).
  • $p$ = Price per unit (selling price).
  • $s$ = Salvage value per unsold unit ($s < c$).
  • $Q$ = The order quantity, our one decision variable.

The key insight comes from marginal analysis. Let $Q^*$ be the optimal order quantity. We should order the $Q^{th}$ unit as long as the expected *gain* from that unit is greater than the expected *loss*.

If we order one more unit (the $Q^{th}$ unit), one of two things will happen:

  1. This unit is sold: This happens if $Demand \ge Q$. The probability of this is $P(D \ge Q) = 1 - F(Q)$. The *gain* from this event is the profit we make, $p - c$.
  2. This unit is NOT sold: This happens if $Demand < Q$. The probability of this is $P(D < Q) = F(Q)$. The *loss* from this event is our cost $c$ minus our salvage $s$, or $c - s$.

    3. At the optimum $Q^*$, the expected gain equals the expected loss.

    $$ \text{Expected Gain} = \text{Expected Loss} $$ $$ (p - c) \times P(D \ge Q^*) = (c - s) \times P(D < Q^*) $$

2. The Critical Ratio

The equation above is the key. Let's simplify the terms.

  • $C_u = \text{Cost of Understocking}$ (per unit) = $p - c$. This is the profit we *miss out on* for every unit we were short.
  • $C_o = \text{Cost of Overstocking}$ (per unit) = $c - s$. This is the net loss we take on every unsold unit.

Now, we substitute these into our equilibrium equation:

$$ C_u \times (1 - F(Q^*)) = C_o \times F(Q^*) $$ $$ C_u - C_u F(Q^*) = C_o F(Q^*) $$ $$ C_u = F(Q^*) (C_o + C_u) $$

This gives the final, famous formula for the Critical Ratio:

The Critical Ratio

$$ F(Q^*) = P(D \le Q^*) = \frac{C_u}{C_o + C_u} $$

This ratio, $CR = \frac{C_u}{C_o + C_u}$, represents the optimal Cycle Service Level (CSL) for a single-period problem. It is the probability that demand will be less than or equal to our order quantity.

2.1 Finding the Optimal Quantity $Q^*$

The formula does not give us $Q^*$ directly. It gives us the *target service level* $F(Q^*)$.

Case 1: Demand is Normally Distributed $D \sim N(\mu, \sigma)$

This is the most common continuous case. We find $Q^*$ just like finding a reorder point.

  1. Calculate the Critical Ratio: $CR = \frac{C_u}{C_o + C_u}$.
  2. Find the corresponding $z$-score: $z = \Phi^{-1}(CR)$ (i.e., `NORM.S.INV(CR)`).
  3. Calculate $Q^* = \mu + z \cdot \sigma$.

Case 2: Demand is Discrete

If demand is given as a table of probabilities, we must build the CDF $F(d) = P(D \le d)$.

  1. Calculate the Critical Ratio, $CR$.
  2. Create a table for demand $d$, $P(D=d)$, and the cumulative $F(d)$.
  3. Find the smallest quantity $d$ for which $F(d) \ge CR$.
  4. This quantity is $Q^*$.
