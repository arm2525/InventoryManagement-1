Theory Essentials: Two Optimization Paradigms

Duration: 1.5 Hours References: Hadley & Whitin (1963); Zipkin (2000); Axsäter (2015)

In Part 1, we derived the cost-optimal $(Q, R)$ policy by assuming a fixed shortage cost, $p$, per unit short. This led to the Newsvendor-like condition for $R$: $F(R) = \frac{p}{p+h}$.

In practice, $p$ is notoriously difficult to estimate. What is the true cost of a stockout? Lost goodwill? A lost customer? Managers are far more comfortable setting a *service target*.

This module reformulates the problem: instead of minimizing cost, we **minimize cost *subject to* a service constraint**.

  • Paradigm 1 (Cost-Based): $\min_{Q,R} \text{TC}(Q,R,p)$. Solved by finding the optimal $p$.
  • Paradigm 2 (Service-Based): $\min_{Q,R} \text{TC}(Q,R)$ s.t. $\text{Service}(Q,R) \ge \text{Target}$.

2. The Cycle Service Level (CSL, $\alpha$) Constraint

This is the simpler of the two service constraints. We want to minimize costs subject to $CSL = \alpha$, where $CSL = P(DDLT \le R)$.

$$\min_{Q,R} \left\{ \frac{KD}{Q} + h\left(\frac{Q}{2} + R - \mu_L\right) \right\}$$ $$\text{Subject to: } P(DDLT \le R) = F(R) = \alpha$$

This problem is **decomposable**. The constraint $F(R) = \alpha$ does not depend on $Q$. It *only* sets the reorder point, $R$.

  1. Find R: The constraint $F(R) = \alpha$ directly gives $R^* = F^{-1}(\alpha)$. For $DDLT \sim N(\mu_L, \sigma_L)$, this is $R^* = \mu_L + z_\alpha \sigma_L$.
  2. Find Q: With $R^*$ now a fixed constant, we just need to minimize the cost function $TC(Q) = \frac{KD}{Q} + \frac{hQ}{2} + h(R^* - \mu_L)$. The derivative $\frac{dTC}{dQ}$ is identical to the basic EOQ model. $$Q^* = \sqrt{\frac{2KD}{h}} = EOQ$$

The $\alpha$-Constrained Policy

The optimal policy subject to a Cycle Service Level $\alpha$ is to set $Q$ and $R$ independently:

$$Q^* = EOQ = \sqrt{\frac{2KD}{h}}$$ $$R^* = \mu_L + z_\alpha \sigma_L$$

3. The Fill Rate (FR, $\beta$) Constraint

This is a far more complex and realistic problem. The Fill Rate (Type 2 service) is the fraction of demand met directly from stock. It is a function of *both* $Q$ and $R$.

Recall from Part 1: $FR = 1 - \frac{\text{Expected shortage per year}}{\text{Total annual demand}}$.

  • Expected shortage per cycle = $E[US(R)] = \int_R^\infty (x-R) f(x) dx$
  • Number of cycles per year = $D/Q$
  • Expected shortage per year = $E[US(R)] \cdot (D/Q)$
$$FR(Q, R) = 1 - \frac{E[US(R)] \cdot (D/Q)}{D} = 1 - \frac{E[US(R)]}{Q}$$

The optimization problem is now:

$$\min_{Q,R} \left\{ \frac{KD}{Q} + h\left(\frac{Q}{2} + R - \mu_L\right) \right\}$$ $$\text{Subject to: } 1 - \frac{E[US(R)]}{Q} \ge \beta$$

The constraint $Q(1-\beta) = E[US(R)]$ clearly shows that $Q$ and $R$ are now **interdependent**. We cannot solve for them separately.

3.1 The Iterative Solution (Hadley-Whitin)

This problem must be solved numerically. The standard approach is an iterative algorithm that finds the $(Q, R)$ pair satisfying two optimality conditions.

  1. Condition 1 (EOQ-like): The optimal $Q$ balances setup cost against holding and *shortage* costs. The optimal $Q$ can be shown to be: $$Q = \sqrt{\frac{2D(K + \text{Imputed Shortage Cost})}{h}}$$
  2. Condition 2 (Newsvendor-like): The optimal $R$ balances holding and shortage costs *at the margin*.

The full iterative algorithm (Axsäter, 2015) finds the $(Q,R)$ pair that satisfies the fill rate constraint and the EOQ trade-off simultaneously. A common, simpler heuristic is to:

  1. Set $Q_0 = EOQ = \sqrt{2KD/h}$.
  2. Find $R_0$ by solving the constraint: $E[US(R_0)] = Q_0(1-\beta)$. (For $DDLT \sim N(\mu_L, \sigma_L)$, this means solving $G_u(z_0) = \frac{Q_0(1-\beta)}{\sigma_L}$ for $z_0$.)
  3. (Optional refinement) Use this $R_0$ to calculate an imputed shortage cost $p$, then recalculate $Q_1$, then $R_1$, and so on, until $(Q_k, R_k)$ converges.

For most practical purposes, the heuristic $(Q_0, R_0)$ is extremely close to optimal.
