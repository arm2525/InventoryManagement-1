Theory Essentials: The Stochastic Dynamic Lot Sizing Problem

Duration: 1.5 Hours References: Scarf (1960); Porteus (2002); Zipkin (2000)

In Part 1, we analyzed two distinct worlds:

  1. Dynamic, Deterministic: The Dynamic Lot Sizing (DLS) problem, solved optimally by Wagner-Whitin.
  2. Static, Stochastic: The Newsvendor problem, solved optimally by the Critical Ratio.

We now combine these challenges: How do we make optimal ordering decisions over a multi-period horizon when demand is **dynamic (stochastic) and not known in advance**?

This is the classic stochastic inventory control problem. It is a **Markov Decision Process (MDP)** and is solved using dynamic programming.

1.1 The Model (The Bellman Formulation)

Let's define the problem over $N$ periods, working backwards (the DP approach).

  • $x$ = Inventory level *before* ordering (the "state").
  • $y$ = Inventory level *after* ordering (the "action" is to order $Q = y-x$).
  • $D$ = Stochastic demand in a period, with PDF $\phi(d)$.
  • $K$ = Fixed ordering cost (if $y > x$).
  • $c$ = Per-unit purchase cost.
  • $L(y)$ = The expected one-period holding/penalty cost, given we start the period with $y$ inventory. This is a Newsvendor cost function! $$ L(y) = \int_0^y h(y-d)\phi(d)dd + \int_y^\infty p(d-y)\phi(d)dd $$ (Where $h$ is holding cost and $p$ is shortage penalty cost.)
  • $\alpha$ = Discount factor ($0 < \alpha \le 1$).

Let $f_n(x)$ = The minimum expected discounted cost for the remaining $n$ periods, given we start with inventory $x$.

The **Bellman Optimality Equation** defines this relationship:

$$ f_n(x) = \min_{y \ge x} \{ K \cdot \delta(y-x) + c(y-x) + L(y) + \alpha \mathbb{E}[f_{n-1}(y-D)] \} $$ Where $\delta(y-x) = 1$ if $y > x$, and $0$ otherwise.

This equation is notoriously difficult to solve. We cannot find a simple closed-form solution. The breakthrough came not from solving for $f_n(x)$, but from proving the *structure* of the optimal policy.

2. The Optimality of (s, S) Policies

In his seminal 1960 paper, Herbert Scarf proved that for this problem, the optimal policy has a specific structure: the **(s, S) policy**.

  • **If inventory $x < s$:** Order $S-x$ to bring inventory up to $S$.
  • **If inventory $x \ge s$:** Do not order.

This policy is defined by two numbers, $s$ (the reorder point) and $S$ (the order-up-to level). This is incredibly powerful—it reduces an infinitely complex problem to finding just two parameters.

2.1 K-Convexity: The Key to the Proof

Scarf's proof is a landmark of operations research. He did not solve the Bellman equation, but rather proved that a key property, **K-convexity**, is preserved from one period to the next.

Definition: K-Convexity

A function $g(x)$ is **K-convex** if $g(x)$ is not necessarily convex, but the "action" function $G(y) = \min_{y \ge x} \{ K\delta(y-x) + g(y) \}$ is convex.

In simpler terms: a function is K-convex if its shape is such that the optimal decision, when faced with a fixed cost $K$, is to "jump" from a lower point ($s$) to a single higher point ($S$).

**Scarf's Proof (Conceptual):**

  1. Base Case: The one-period cost function $c(y-x) + L(y)$ is K-convex (it's convex, which is a stronger condition).
  2. Inductive Step: Scarf proved that if the $n$-period cost function $f_n(x)$ is K-convex, then the $(n+1)$-period cost function $f_{n+1}(x)$ (which depends on $f_n$) *must also be K-convex*.
  3. Conclusion: Since the property holds for all $n$, the optimal policy in every period must be an (s, S) policy.

This proves that the simple, intuitive (s, S) policy is not just a heuristic—it is the *provably optimal* solution to the multi-period stochastic inventory problem with fixed order costs.
